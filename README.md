## 🧬 `whoami`

> **An independent technology enthusiast exploring the boundary between Android and desktop Linux.**

I’m interested in making mobile hardware do more: experimenting with Linux desktop environments, ARM64 systems, graphics stacks, and terminal-based workflows.

- 📱 **Platform:** Android + Termux
- 🐧 **Ecosystem:** Linux desktop and command-line tools
- ⚙️ **Architecture:** ARM64
- 🖥️ **Focus:** Running and adapting desktop Linux technologies on mobile hardware
- 🔬 **Approach:** Experiment, test, document, improve
